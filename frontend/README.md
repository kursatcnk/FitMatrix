# FitMatrix frontend

React, TypeScript, Vite, Zustand ve React Three Fiber tabanlı 3D masa yerleşim editörüdür. Kaynak kodun ana kullanım ve disk politikası belgeleri üst dizindeki `README.md` ve `docs/disk-policy.md` dosyalarındadır.

```powershell
. ..\scripts\use-dev-drives.ps1
npm run dev
```

Doğrulama:

```powershell
npm run lint
npm test
npm run build
```
